# Validation Checklist

1. Verify every footprint against its datasheet.
2. Verify the exact 8x8 matrix pinout.
3. Run schematic ERC.
4. Run PCB DRC.
5. Confirm zero unconnected nets.
6. Inspect Gerbers in a viewer.
7. Power the board with current limiting for first test.
8. Test one row before enabling multiplexing.
9. Confirm no LED ghosting and acceptable brightness.
